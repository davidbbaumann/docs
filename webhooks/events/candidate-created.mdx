---
title: "Candidate created"
description: "Sent when a candidate is created in your Nexus workspace."
---

<Badge color="blue">WEBHOOK</Badge> `candidate.created`

Nexus sends this event to your endpoint when a candidate is created. The payload is intentionally thin and contains identifiers only. Load the current record via the Nexus API or MCP. For headers, signature verification and retries, see the [overview](/webhooks).

## When it is sent

A candidate is created.

## Body

`application/json`

<ParamField body="id" type="string" required>
  Unique event ID (`evt_...`). Identical to the `webhook-id` header. Use it for deduplication.
</ParamField>

<ParamField body="event" type="string" required>
  Event type. Always `candidate.created`.
</ParamField>

<ParamField body="timestamp" type="string" required>
  ISO 8601 UTC time when the event occurred.
</ParamField>

<ParamField body="workspace_id" type="string" required>
  UUID of the Nexus workspace.
</ParamField>

<ParamField body="actor" type="object" required>
  Who triggered the event.

  <Expandable title="actor">
    <ParamField body="type" type="string" required>
      `user`, `agent` or `system`.
    </ParamField>

    <ParamField body="id" type="string | null" required>
      UUID of the user or agent, if known.
    </ParamField>

    <ParamField body="channel" type="string" required>
      `agent` if an AI agent made the change, otherwise `system`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="data" type="object" required>
  Identifiers of the affected record.

  <Expandable title="data">
    <ParamField body="entity_type" type="string" required>
      Always `candidate`.
    </ParamField>

    <ParamField body="id" type="string" required>
      UUID of the candidate.
    </ParamField>
  </Expandable>
</ParamField>
